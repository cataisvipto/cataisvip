## 数据能力

### 💡 数据演进四级路线（2026-07-26）
数据全面程度始终比产品需求**领先半步**，按信号触发升级，不为全面而全面：

| 级 | 内容 | 触发信号 | 成本 |
|---|---|---|---|
| L1 广度扩容 | Search API 开分页（每查询 100→最多 1000 条）+ 增加查询词，池子 1267→5000+ | 想拆更细分类（如视频生成）或漏网项目变多；**建议周榜上线后做** | CI 多跑约 7 分钟 |
| L2 深度增补 | 仅对上榜 ~280 项目补贡献者数/release 频率/issue 关闭率（~280 次请求） | 算法升 v2.x 或做项目详情页 | 免费 |
| L3 形态升级 | 快照 JSON → SQLite 单文件（仍在 git，可 SQL 聚合）；再往后 Neon Postgres 免费档 | 出现"查单项目 90 天走势"类需求 | 免费 |
| L4 终极形态 | GH Archive @ BigQuery 公共数据集（每月 1TB 免费查询）：回溯任意项目完整 star 历史、账号级反刷分分析 | 有稳定流量、做年度深度报告时 | 免费额度内 |

### ❌ 快照滚动窗口延长到 18 个月以上（2026-07-31，放弃）
评估结论：不做。>18 个月场景月初冷归档（月粒度）已覆盖；git 历史保留全部被清理快照可回溯兜底；超长日粒度回溯正解是 GH Archive @ BigQuery（L4），无限加长窗口只堆文件数、无消费场景。
